
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic Hangman word-guessing game using Python strings, loops, and conditionals. You'll practice random selection, user input handling, and game state management while creating an interactive game.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a Hangman game application where players can guess letters to uncover a hidden word. The game should manage game state, validate user input, and provide clear feedback on progress and game outcome.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and display current progress in underscore format (_ _ _ _)
- Track and display incorrect guesses remaining
- End when the word is guessed or attempts are exhausted
- Display appropriate win/lose messages with the final word revealed
